# 基本情報技術者試験 科目B対策アプリ

## 概要

基本情報技術者試験の科目B（アルゴリズム・プログラミング、情報セキュリティ）に対応した学習支援Webアプリケーションです。

## 🎯 試験仕様準拠

- **アルゴリズム問題**: 16問
- **情報セキュリティ問題**: 4問
- **合計**: 20問（実際の試験と同じ構成）

## ✨ 主な機能

### 📚 学習モード
- **全20問チャレンジ**: 本番と同じ問題構成
- **分野別学習**: アルゴリズム（16問）、情報セキュリティ（4問）
- **詳細解説**: 各問題に充実した解説を付属

### 📊 学習管理
- **進捗表示**: リアルタイム進捗バーとタイマー
- **学習履歴**: 受験回数、正答率、分野別成績の記録
- **ブックマーク**: 重要問題の保存・復習機能

### 🎨 ユーザビリティ
- **レスポンシブデザイン**: PC・タブレット・スマートフォン対応
- **アクセシビリティ**: 高コントラストモード、ダークモード対応
- **直感的操作**: わかりやすいUI/UX設計

## 📝 問題内容

### アルゴリズム問題（16問）
- **ソートアルゴリズム**: バブルソート、挿入ソート、選択ソート
- **探索アルゴリズム**: 線形探索、二分探索
- **データ構造**: スタック、キュー操作
- **再帰処理**: 階乗計算、文字列処理
- **配列操作**: 最大値・最小値検索、重複検出
- **トレース問題**: プログラム実行過程の追跡
- **計算問題**: mod演算、二次元配列

### 情報セキュリティ問題（4問）
- **暗号化技術**: 共通鍵暗号、公開鍵暗号
- **認証技術**: デジタル署名の仕組み
- **ネットワークセキュリティ**: ファイアウォール機能
- **Webセキュリティ**: 攻撃手法と対策

## 🚀 使用方法

### 1. セットアップ
```bash
# ファイルを適当なフォルダに配置
fe_exam_app/
├── index.html
├── style.css
├── script.js
├── questions.js
└── README.md
```

### 2. 起動方法
- **ローカル環境**: `index.html` をブラウザで直接開く
- **Webサーバー**: HTTPサーバー経由でアクセス（推奨）

```bash
# Python 3の場合
python -m http.server 8000

# Node.jsの場合  
npx http-server

# ブラウザで http://localhost:8000 にアクセス
```

### 3. 操作方法

#### 学習開始
1. メニューから学習モードを選択
2. 問題に回答し「回答する」をクリック
3. 解説を確認後、次の問題へ進む

#### 便利機能
- **ブックマーク**: 重要問題を保存
- **学習履歴**: 過去の成績を確認
- **復習機能**: 間違えた問題を再学習

## 📈 学習データ

### 保存される情報
- 受験履歴（回数、日時、成績）
- 分野別正答率統計
- ブックマーク問題一覧
- 個別問題の正解/不正解履歴

### データ管理
- **保存場所**: ブラウザのLocal Storage
- **容量**: 約5-10MB（履歴100件分）
- **プライバシー**: 全てローカル保存（外部送信なし）

## 🎓 学習のコツ

### 効果的な使い方
1. **全体把握**: まず全20問チャレンジで実力チェック
2. **分野別強化**: 苦手分野を重点的に学習
3. **解説熟読**: 間違えた問題の解説を必ず確認
4. **反復練習**: ブックマーク機能で重要問題を繰り返し

### アルゴリズム問題対策
- **トレース練習**: 変数の値変化を丁寧に追跡
- **計算量理解**: O記法での性能評価を意識
- **パターン認識**: ソート・探索の典型パターンを覚える

### セキュリティ問題対策
- **基本概念**: 暗号化、認証、完全性の違いを理解
- **技術分類**: 対称暗号と非対称暗号の特徴を整理
- **攻撃手法**: 各攻撃の目的と対策を関連付けて学習

## 📞 サポート

### よくある質問
**Q: データが消えてしまいました**
A: ブラウザのLocal Storageをクリアすると学習履歴が削除されます。定期的なバックアップをお勧めします。

**Q: スマートフォンで使えますか？**
A: はい、レスポンシブデザインによりスマートフォンでも快適に利用できます。

**Q: オフラインで使えますか？**
A: はい、一度ブラウザに読み込めばインターネット接続なしで動作します。
