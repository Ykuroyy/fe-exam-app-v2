📄 PDF問題ファイル管理

アルゴリズム問題に添付するPDFファイルを管理できます

📁 PDFファイルをアップロード

クリックするかファイルをドラッグ＆ドロップしてください

📋 アップロード済みファイル

🔧 使用方法

  1. PDFファイルをアップロードします
  2. 生成されたURLをコピーします
  3. 問題データの pdfUrl フィールドに貼り付けます
  4. アプリで問題を表示すると、PDFが自動的に表示されます

📝 問題データ設定例：

{
    id: 'alg001',
    category: 'algorithm', 
    level: 'basic',
    text: '次の図を参照して問題を解いてください。',
    pdfUrl: '/pdfs/algorithm_001.pdf',  // ← ここに生成されたURLを設定
    choices: [...],
    correct: 0,
    explanation: '...'
}
